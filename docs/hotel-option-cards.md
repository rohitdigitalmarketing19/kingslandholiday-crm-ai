Hotel options and B2B Word export

The hotel comparison uses two cards side by side, with navy headers, night totals, hotel and meal details, and gold price footers. Narrow containers stack the cards. Both prices retain the existing display uplift for crossed-out prices; actual selling prices are unchanged.

All B2B download buttons now generate a genuine .docx document with native editable paragraphs and hotel comparison cells. It includes customer/trip details, both option prices, travel details, inclusions, exclusions, itinerary, optional available photos and quote terms. It omits agency logos, advisor contacts and partner branding. Normal customer PDF export is unchanged. The docx library loads only when the B2B action is used. Photos that cannot be fetched within the bounded wait are omitted; itinerary text remains complete.

Verification: TypeScript, desktop/mobile card layout, six PDF themes, DOCX MIME and OOXML contents, native editable text, images and absent branding. A generated two-page sample was opened and rendered by Microsoft Word and visually reviewed. The packaged LibreOffice renderer could not run because LibreOffice is unavailable.
